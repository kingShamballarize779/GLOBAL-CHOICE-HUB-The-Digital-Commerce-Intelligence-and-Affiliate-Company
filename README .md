# GLOBAL CHOICE HUB™ — Foundation v0.1

Independent static foundation for Global Choice Hub™.

## Operating principle
DISCOVER → CURATE → REFER → EARN

## Trust boundary
No product, merchant, price, offer, coupon, affiliate relationship, URL or verification claim is invented here.

The product data file is intentionally empty until the authoritative GCH Batch 1 source is connected. The known reconciliation is 100 source rows → 98 canonical products, with 2 duplicate merges.

## Files
- `index.html` — public headquarters shell
- `styles.css` — visual system
- `app.js` — catalogue/category rendering and search
- `data/products.json` — external data boundary

## Deployment direction
Designed for Cloudflare Pages or Cloudflare Workers static assets, with Git as the source-control layer.
